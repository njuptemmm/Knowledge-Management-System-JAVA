# 知识管理系统 v0.1.0（RAG 智能问答）实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在已交付的后端之上新增 M5 智能问答域，让用户用自然语言提问，系统从知识库召回相关内容交给大模型生成答案，并给出可点击的引用来源。

**Architecture:** 新增模块 M5 `qa`，与既有 M0–M4 并列。索引侧由既有的 Spring 事件机制驱动（条目发布/编辑/归档/删除 → 异步重建该条目索引）；问答侧走「问题向量化 → 向量召回 → 可见性二次过滤 → 组装 prompt → LLM 流式生成 → SSE 返回」。M5 不拥有数据库表，只拥有一个持久化的向量索引文件与 Redis 会话命名空间。

**Tech Stack:** Spring AI 1.0.0-M6 · 火山方舟 doubao-embedding-vision（自研 EmbeddingModel 适配）· Kimi kimi-k2.6（生成）· SimpleVectorStore（持久化到文件）· SSE

**Spec:** `docs/spec/kms-design-v0.0.1.md`（§12 Backlog 的 P0 项）

---

## Global Constraints

承接后端计划的全部约束（Java 17、Spring Boot 3.5.3、`com.njupt.kms`、`Result<T>` 统一响应、模块只读写自己的表、端口 8090、SQL 脚本带 `--default-character-set=utf8mb4`、Mockito 打桩写显式类型）。以下为 RAG 新增约束，**全部来自 2026-10-14 的实测，不是推测**：

| 编号 | 约束 | 违反后果 |
|---|---|---|
| RC1 | **Kimi 的 `temperature` 必须为 `1`** | 传其他值直接 HTTP 400：`invalid temperature: only 1 is allowed for this model` |
| RC2 | **火山方舟向量模型只能走 `/embeddings/multimodal`** | 走标准 `/embeddings` 返回 400 `does not support this api` |
| RC3 | **embedding 端点不支持批量**：传多条文本只返回 1 条向量 | 必须逐条调用，提速只能靠并发 |
| RC4 | 单条 embedding 延迟约 **350ms** | 500 块串行需 3 分钟；索引服务必须并发 |
| RC5 | Moonshot **不提供任何 embedding 模型** | 生成与向量化必须是两套独立配置，不能共用一个 key |
| RC6 | 向量维度 **2048** | 向量库文件体积较大，写入频率要低（每次索引操作只 save 一次，不逐块 save） |
| RC7 | **密钥严禁进代码。** 两个 key 都放 `application-local.yaml`（已被 gitignore）。`.example` 文件只放占位符 | 凭据泄露 |

**未配置密钥时的行为**：`app.rag.enabled=false`（默认），问答接口返回明确提示而非 500。**其余功能完全不受影响。**

## 对 spec 的补充（本计划确立，spec 后续同步）

1. **新增模块 M5 智能问答域**。spec §12 原计划把 RAG 并入 M3，但切块/索引/向量召回/LLM 编排/会话管理这一整套关注点与词法检索无关，塞进 M3 会让 M3 失去边界。M5 与 M0–M4 并列。
2. **M5 无数据库表**。只拥有：向量索引文件（`data/vector-index.json`）、Redis 会话命名空间（`kms:qa:*`）。
3. **只有 `PUBLISHED` 条目进入索引**。草稿与归档内容不索引，从根源杜绝通过问答泄露未发布内容。
4. **问答链路固定为 SSE 流式**。非流式会让用户面对 3–5 秒无反馈的白屏。

```java
package com.njupt.kms.qa.config;

import com.fasterxml.jackson.annotation.JsonIgnoreProperties;
import lombok.extern.slf4j.Slf4j;
import org.springframework.ai.document.Document;
import org.springframework.ai.embedding.AbstractEmbeddingModel;
import org.springframework.ai.embedding.Embedding;
import org.springframework.ai.embedding.EmbeddingRequest;
import org.springframework.ai.embedding.EmbeddingResponse;
import org.springframework.http.HttpHeaders;
import org.springframework.http.MediaType;
import org.springframework.web.client.RestClient;
import org.springframework.web.client.RestClientResponseException;

import java.util.ArrayList;
import java.util.List;
import java.util.Map;

/**
 * 火山方舟 doubao-embedding-vision 的 Spring AI 适配。
 *
 * <p>该模型**只支持多模态端点** {@code /embeddings/multimodal}（实测确认）：
 * 走标准 {@code /embeddings} 会返回 400 {@code does not support this api}。
 * 因此不能使用 Spring AI 的 OpenAI 自动配置，必须自研。
 *
 * <p>端点**也不支持批量**：一次传多条文本只会返回一条向量（被当作一条多模态消息
 * 合并处理）。故 {@link #call} 逐条发请求。提速由调用方在索引层做并发，
 * 不在本类内做（本类无状态、可安全并发调用）。
 */
@Slf4j
public class VolcArkEmbeddingModel extends AbstractEmbeddingModel {

    private static final String MULTIMODAL_PATH = "/embeddings/multimodal";

    private final RestClient restClient;
    private final String model;

    public VolcArkEmbeddingModel(RestClient.Builder builder, String baseUrl, String apiKey, String model) {
        this.model = model;
        this.restClient = builder
                .baseUrl(baseUrl)
                .defaultHeader(HttpHeaders.AUTHORIZATION, "Bearer " + apiKey)
                .defaultHeader(HttpHeaders.CONTENT_TYPE, MediaType.APPLICATION_JSON_VALUE)
                .build();
        log.info("[VolcArkEmbeddingModel] baseUrl={} model={}", baseUrl, model);
    }

    @Override
    public EmbeddingResponse call(EmbeddingRequest request) {
        List<String> inputs = request.getInstructions();
        List<Embedding> embeddings = new ArrayList<>(inputs.size());
        for (int i = 0; i < inputs.size(); i++) {
            embeddings.add(new Embedding(embedOne(inputs.get(i)), i));
        }
        return new EmbeddingResponse(embeddings);
    }

    @Override
    public float[] embed(Document document) {
        return embedOne(document.getText());
    }

    @Override
    public float[] embed(String text) {
        return embedOne(text);
    }

    private float[] embedOne(String text) {
        Map<String, Object> body = Map.of(
                "model", model,
                // 空文本不能让整条索引失败，归一化为空串
                "input", List.of(Map.of("type", "text", "text", text == null ? "" : text.strip())));
        try {
            ArkResponse response = restClient.post()
                    .uri(MULTIMODAL_PATH)
                    .body(body)
                    .retrieve()
                    .body(ArkResponse.class);
            if (response == null || response.data() == null || response.data().embedding() == null) {
                throw new IllegalStateException("火山方舟 embedding 响应格式异常");
            }
            List<Float> vector = response.data().embedding();
            float[] result = new float[vector.size()];
            for (int i = 0; i < vector.size(); i++) {
                result[i] = vector.get(i);
            }
            return result;
        } catch (RestClientResponseException e) {
            // 4xx/5xx 带上响应体，否则排查时只能看到一行状态码
            throw new IllegalStateException(
                    "火山方舟 embedding 调用失败: HTTP %d %s".formatted(
                            e.getStatusCode().value(), e.getResponseBodyAsString()), e);
        }
    }

    @JsonIgnoreProperties(ignoreUnknown = true)
    record ArkResponse(ArkData data) {
    }

    @JsonIgnoreProperties(ignoreUnknown = true)
    record ArkData(List<Float> embedding) {
    }
}
```

```java
package com.njupt.kms.qa.config;

import com.njupt.kms.common.BusinessException;
import lombok.extern.slf4j.Slf4j;
import org.springframework.ai.chat.client.ChatClient;
import org.springframework.ai.embedding.EmbeddingModel;
import org.springframework.ai.openai.OpenAiChatModel;
import org.springframework.ai.vectorstore.SimpleVectorStore;
import org.springframework.ai.vectorstore.VectorStore;
import org.springframework.context.annotation.Bean;
import org.springframework.context.annotation.Configuration;

import java.io.File;
import java.util.concurrent.Executor;
import java.util.concurrent.ThreadPoolExecutor;
import java.util.concurrent.LinkedBlockingQueue;
import java.util.concurrent.TimeUnit;

@Slf4j
@Configuration
public class RagConfig {

    /**
     * 问答生成用的 ChatClient。
     *
     * <p>温度**必须为 1**：Kimi 的 kimi-k2.6 只接受 1，传其他值直接 HTTP 400
     * （实测：invalid temperature: only 1 is allowed for this model）。
     */
    @Bean
    public ChatClient qaChatClient(OpenAiChatModel model) {
        return ChatClient.builder(model)
                .defaultSystem(QaPrompts.SYSTEM)
                .build();
    }

    @Bean
    public EmbeddingModel volcArkEmbeddingModel(RagProperties props) {
        if (props.getEmbedding().getBaseUrl() == null || props.getEmbedding().getApiKey() == null) {
            // 返回一个一旦被调用就报错的实现，而不是返回 null：
            // 这样 Bean 装配不会失败，未启用 RAG 时其余功能照常工作
            return new UnavailableEmbeddingModel();
        }
        return new VolcArkEmbeddingModel(
                org.springframework.web.client.RestClient.builder(),
                props.getEmbedding().getBaseUrl(),
                props.getEmbedding().getApiKey(),
                props.getEmbedding().getModel());
    }

    /**
     * 向量库。SimpleVectorStore 默认纯内存、重启即丢，
     * 构造时显式加载磁盘文件，就不存在这个问题。
     */
    @Bean
    public VectorStore vectorStore(EmbeddingModel embeddingModel, RagProperties props) {
        SimpleVectorStore store = SimpleVectorStore.builder(embeddingModel).build();
        File file = new File(props.getVectorStore().getPath());
        if (file.exists()) {
            store.load(file);
            log.info("[RAG] 已从 {} 加载向量索引", file.getAbsolutePath());
        } else {
            log.info("[RAG] 向量索引文件不存在，使用空索引：{}", file.getAbsolutePath());
        }
        return store;
    }

    /** 向量化线程池。RC4：单条约 350ms，串行索引 500 块需 3 分钟，必须并发。 */
    @Bean("embeddingExecutor")
    public Executor embeddingExecutor(RagProperties props) {
        ThreadPoolExecutor executor = new ThreadPoolExecutor(
                props.getEmbedding().getConcurrency(),
                props.getEmbedding().getConcurrency(),
                60L, TimeUnit.SECONDS,
                new LinkedBlockingQueue<>(),
                r -> {
                    Thread t = new Thread(r, "rag-embed-" + System.nanoTime() % 10000);
                    t.setDaemon(true);
                    return t;
                });
        log.info("[RAG] embedding 线程池并发度 = {}", props.getEmbedding().getConcurrency());
        return executor;
    }

    /** 未配置密钥时的占位实现。被调用即给出可读提示，而不是 NPE。 */
    static class UnavailableEmbeddingModel implements EmbeddingModel {

        @Override
        public org.springframework.ai.embedding.EmbeddingResponse call(
                org.springframework.ai.embedding.EmbeddingRequest request) {
            throw unavailable();
        }

        @Override
        public float[] embed(org.springframework.ai.document.Document document) {
            throw unavailable();
        }

        @Override
        public int dimensions() {
            return 0;
        }

        private BusinessException unavailable() {
            return new BusinessException("问答功能未启用：请在 application-local.yaml 中配置 app.rag.embedding.*");
        }
    }
}
```

```java
package com.njupt.kms.qa.chunk;

import com.njupt.kms.qa.config.RagProperties;
import org.springframework.stereotype.Service;
import org.springframework.util.StringUtils;

import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;
import java.util.List;
import java.util.regex.Matcher;
import java.util.regex.Pattern;

/**
 * 切块算法：Markdown 文本 → 适合向量化的块列表。
 *
 * <p>两步走：先按 Markdown 标题切成「节」（保留语义边界，并记录标题路径），
 * 超长的节再按长度切分并保留重叠（避免语义在切点处断裂）。
 *
 * <p>纯计算，不依赖 Spring 容器以外的任何东西，便于独立测试。
 */
@Service
public class ChunkingService {

    private static final Pattern HEADING = Pattern.compile("^(#{1,6})\\s+(.*)$");

    private final int maxLength;
    private final int overlap;

    public ChunkingService(RagProperties properties) {
        this(properties.getChunk().getMaxLength(), properties.getChunk().getOverlap());
    }

    public ChunkingService(int maxLength, int overlap) {
        this.maxLength = maxLength;
        this.overlap = Math.max(0, Math.min(overlap, maxLength / 2));
    }

    /**
     * 把一篇文档切成块。
     *
     * @param itemId 所属条目 id
     * @param text   Markdown 正文
     * @param title  文档标题，作为没有标题结构时的路径
     */
    public List<Chunk> split(Long itemId, String text, String title) {
        List<Chunk> chunks = new ArrayList<>();
        if (!StringUtils.hasText(text)) {
            return chunks;
        }

        for (Section section : splitIntoSections(text, title)) {
            for (String piece : splitByLength(section.body())) {
                if (StringUtils.hasText(piece)) {
                    chunks.add(new Chunk(itemId, chunks.size(), piece.strip(), section.headingPath()));
                }
            }
        }
        return chunks;
    }

    /** 一节：标题路径 + 正文。 */
    private record Section(String headingPath, String body) {
    }

    /**
     * 按 Markdown 标题切节，维护标题栈以生成路径。
     *
     * <p>遇到更高级或同级的标题时，栈中不低于它的层级被弹出。
     * 这保证了 {@code # A / ## B / # C} 得到路径 {@code A > B} 与 {@code C}，
     * 而不是错误的 {@code A > B > C}。
     */
    private List<Section> splitIntoSections(String text, String title) {
        List<Section> sections = new ArrayList<>();
        Deque<String> headingStack = new ArrayDeque<>();
        List<Integer> levelStack = new ArrayList<>();

        String currentPath = StringUtils.hasText(title) ? title.strip() : "正文";
        StringBuilder buffer = new StringBuilder();

        for (String line : text.split("\r?\n", -1)) {
            Matcher matcher = HEADING.matcher(line.strip());
            if (matcher.matches()) {
                flush(sections, currentPath, buffer);

                int level = matcher.group(1).length();
                String heading = matcher.group(2).strip();

                while (!levelStack.isEmpty() && levelStack.get(levelStack.size() - 1) >= level) {
                    levelStack.remove(levelStack.size() - 1);
                    headingStack.removeLast();
                }
                levelStack.add(level);
                headingStack.addLast(heading);
                currentPath = String.join(" > ", headingStack);
            } else {
                buffer.append(line).append('\n');
            }
        }
        flush(sections, currentPath, buffer);
        return sections;
    }

    private void flush(List<Section> sections, String path, StringBuilder buffer) {
        String body = buffer.toString().strip();
        if (!body.isEmpty()) {
            sections.add(new Section(path, body));
        }
        buffer.setLength(0);
    }

    /**
     * 按长度切分，保留重叠。
     *
     * <p>优先在空行处断开（段落边界），找不到再在句末标点处断，最后才硬切，
     * 尽量减少把一句话劈成两半。
     */
    private List<String> splitByLength(String text) {
        List<String> pieces = new ArrayList<>();
        String remaining = text;

        while (remaining.length() > maxLength) {
            int cut = findBreakPoint(remaining, maxLength);
            pieces.add(remaining.substring(0, cut));

            int nextStart = Math.max(0, cut - overlap);
            if (nextStart >= cut) {
                nextStart = cut;   // overlap 为 0 时避免死循环
            }
            remaining = remaining.substring(nextStart);
        }
        if (!remaining.isBlank()) {
            pieces.add(remaining);
        }
        return pieces;
    }

    /** 在 [0, limit] 内找一个尽量自然的断点。 */
    private int findBreakPoint(String text, int limit) {
        int paragraph = text.lastIndexOf("\n\n", limit);
        if (paragraph > limit / 2) {
            return paragraph + 2;
        }
        for (String punct : List.of("。", "！", "？", "；", "\n", ". ")) {
            int index = text.lastIndexOf(punct, limit);
            if (index > limit / 2) {
                return index + punct.length();
            }
        }
        return limit;
    }
}
```

```java
import java.time.LocalDateTime;
```

```java
/**
 * 向量索引的构建与维护。
 *
 * <p>只索引 {@code PUBLISHED} 条目——草稿与归档内容不进索引，
 * 从根源杜绝通过问答泄露未发布内容（见 Global Constraints 第 3 条）。
 */

@Service
public class IndexingService {

    private final VectorStore vectorStore;
    private final EmbeddingModel embeddingModel;
    private final ChunkingService chunkingService;
    private final Executor embeddingExecutor;
    private final RagProperties properties;
    private final ItemContentLoader contentLoader;

    private volatile LocalDateTime lastRebuildAt;

    public IndexingService(VectorStore vectorStore,
                           EmbeddingModel embeddingModel,
                           ChunkingService chunkingService,
                           @Qualifier("embeddingExecutor") Executor embeddingExecutor,
                           RagProperties properties,
                           ItemContentLoader contentLoader) {
        this.vectorStore = vectorStore;
        this.embeddingModel = embeddingModel;
        this.chunkingService = chunkingService;
        this.embeddingExecutor = embeddingExecutor;
        this.properties = properties;
        this.contentLoader = contentLoader;
    }

    /** 重建单个条目的索引（含附件文本）。先清旧块，避免重复累积。 */
    public void indexItem(Long itemId, String title, String content) {
        removeItem(itemId);

        List<Chunk> chunks = new ArrayList<>(chunkingService.split(itemId, content, title));
        if (chunks.isEmpty()) {
            log.debug("[RAG] 条目 {} 无有效内容，跳过索引", itemId);
            return;
        }

        List<Document> documents = embedConcurrently(chunks, title);
        if (!documents.isEmpty()) {
            vectorStore.add(documents);
            log.info("[RAG] 条目 {} 索引完成，{} 块", itemId, documents.size());
        }
    }

    public void indexItem(Long itemId) {
        ItemContentLoader.ItemContent content = contentLoader.load(itemId);
        if (content == null) {
            log.debug("[RAG] 条目 {} 不可索引（不存在或未发布），已跳过", itemId);
            removeItem(itemId);
            return;
        }
        indexItem(itemId, content.title(), content.content());
    }

    /** 从索引移除某条目的全部块。 */
    public void removeItem(Long itemId) {
        try {
            vectorStore.delete("itemId == " + itemId);
        } catch (Exception e) {
            log.warn("[RAG] 移除条目 {} 的索引失败", itemId, e);
        }
    }

    /** 并发向量化。RC3/RC4：端点不支持批量且单条约 350ms，只能并发。 */
    private List<Document> embedConcurrently(List<Chunk> chunks, String title) {
        List<CompletableFuture<Document>> futures = chunks.stream()
                .map(chunk -> CompletableFuture.supplyAsync(() -> toDocument(chunk, title), embeddingExecutor))
                .toList();

        List<Document> documents = new ArrayList<>(chunks.size());
        for (CompletableFuture<Document> future : futures) {
            try {
                documents.add(future.join());
            } catch (Exception e) {
                // 单块失败不能让整条索引失败，其余块照常入库
                log.warn("[RAG] 单块向量化失败，已跳过: {}", e.getMessage());
            }
        }
        return documents;
    }

    private Document toDocument(Chunk chunk, String title) {
        return new Document(chunk.docId(), chunk.text(), Map.of(
                "itemId", chunk.itemId(),
                "title", title == null ? "" : title,
                "headingPath", chunk.headingPath(),
                "chunkIndex", chunk.index()));
    }

    /** 全量重建。返回重建后的状态。 */
    public IndexStatus rebuildAll() {
        Set<Long> itemIds = contentLoader.allIndexableItemIds();
        AtomicInteger ok = new AtomicInteger();
        AtomicInteger failed = new AtomicInteger();

        for (Long itemId : itemIds) {
            try {
                indexItem(itemId);
                ok.incrementAndGet();
            } catch (Exception e) {
                failed.incrementAndGet();
                log.warn("[RAG] 条目 {} 重建失败", itemId, e);
            }
        }

        lastRebuildAt = LocalDateTime.now();
        log.info("[RAG] 全量重建完成：成功 {}，失败 {}，共 {} 块", ok.get(), failed.get(), countChunks());
        return status();
    }

    public IndexStatus status() {
        if (!properties.isEnabled()) {
            return IndexStatus.disabled();
        }
        return new IndexStatus(true, countItems(), countChunks(), lastRebuildAt);
    }

    /** 统计查询的取回上限。课程设计的数据规模远小于此值。 */
    private static final int COUNT_PROBE_LIMIT = 2000;

    /**
     * SimpleVectorStore 不提供计数接口，只能用一个查询把文档取回来数。
     *
     * <p>阈值设为 0 表示不做相似度过滤，topK 取一个足够大的常量。
     * 块数超过 {@value #COUNT_PROBE_LIMIT} 时计数会封顶——这是本实现的已知上限，
     * 记入文档而不是假装没有。
     */
    private List<Document> allDocuments() {
        try {
            return vectorStore.similaritySearch(SearchRequest.builder()
                    .query("统计")
                    .topK(COUNT_PROBE_LIMIT)
                    .similarityThreshold(0.0)
                    .build());
        } catch (Exception e) {
            log.debug("[RAG] 统计索引文档失败: {}", e.getMessage());
            return List.of();
        }
    }

    private int countChunks() {
        return allDocuments().size();
    }

    private int countItems() {
        return (int) allDocuments().stream()
                .map(d -> d.getMetadata().get("itemId"))
                .filter(java.util.Objects::nonNull)
                .distinct()
                .count();
    }
}
```

```java
package com.njupt.kms.qa.index;

import com.njupt.kms.common.event.KnowledgeIndexEvent;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.scheduling.annotation.Async;
import org.springframework.stereotype.Component;
import org.springframework.transaction.event.TransactionPhase;
import org.springframework.transaction.event.TransactionalEventListener;

/**
 * 条目变更后异步重建索引。
 *
 * <p>复用 M2 附件解析同一套机制：事务提交后才执行，避免读到未提交数据；
 * 整体吞掉异常，索引失败绝不能反过来让发布/编辑操作失败。
 */
@Slf4j
@Component
@RequiredArgsConstructor
public class IndexingEventListener {

    private final IndexingService indexingService;

    @Async("embeddingExecutor")
    @TransactionalEventListener(phase = TransactionPhase.AFTER_COMMIT)
    public void onKnowledgeChanged(KnowledgeIndexEvent event) {
        if (event == null || event.itemId() == null) {
            return;
        }
        try {
            if (event.action() == KnowledgeIndexEvent.Action.REMOVE) {
                indexingService.removeItem(event.itemId());
            } else {
                indexingService.indexItem(event.itemId());
            }
        } catch (Exception e) {
            log.error("[RAG] 条目 {} 索引更新失败，不影响主流程", event.itemId(), e);
        }
    }
}
```

```java
package com.njupt.kms.qa.retrieve;

import com.njupt.kms.common.BusinessException;
import com.njupt.kms.qa.config.RagProperties;
import lombok.extern.slf4j.Slf4j;
import org.springframework.ai.document.Document;
import org.springframework.ai.vectorstore.SearchRequest;
import org.springframework.ai.vectorstore.VectorStore;
import org.springframework.stereotype.Service;
import org.springframework.util.StringUtils;

import java.util.ArrayList;
import java.util.Collection;
import java.util.LinkedHashMap;
import java.util.List;
import java.util.Map;
import java.util.Set;
import java.util.function.Function;

/**
 * 向量召回。
 *
 * <p>召回后必须按**当前真实可见性**二次过滤：索引与状态变更之间存在时间窗，
 * 只信索引里的 metadata 会有窗口期漏出已归档内容。
 */
@Slf4j
@Service
public class RetrievalService {

    private final VectorStore vectorStore;
    private final RagProperties properties;
    /** 给定 itemId 集合，返回当前真正可见的子集。测试中注入假实现。 */
    private final Function<Collection<Long>, Set<Long>> visibilityResolver;

    public RetrievalService(VectorStore vectorStore,
                            RagProperties properties,
                            Function<Collection<Long>, Set<Long>> visibilityResolver) {
        this.vectorStore = vectorStore;
        this.properties = properties;
        this.visibilityResolver = visibilityResolver;
    }

    /**
     * 召回与问题相关的块。
     *
     * <p>可见性由注入的 {@code visibilityResolver} 判定，它内部读取
     * {@link com.njupt.kms.security.CurrentUser}，与列表/检索接口用的是同一套规则。
     * 召回发生在请求线程上（流式开始之前），因此 ThreadLocal 可用。
     */
    public List<RetrievedChunk> retrieve(String question) {
        if (!StringUtils.hasText(question)) {
            throw new BusinessException("问题不能为空");
        }
        if (!properties.isEnabled()) {
            throw new BusinessException("问答功能未启用：请在 application-local.yaml 中配置 app.rag.*");
        }

        List<RetrievedChunk> candidates = vectorSearch(question.strip(), properties.getRetrieve().getTopK() * 3);
        if (candidates.isEmpty()) {
            return List.of();
        }

        Set<Long> visible = visibilityResolver.apply(
                candidates.stream().map(RetrievedChunk::itemId).distinct().toList());

        Map<Long, RetrievedChunk> bestPerItem = new LinkedHashMap<>();
        for (RetrievedChunk candidate : candidates) {
            if (candidate.score() < properties.getRetrieve().getMinScore()) {
                continue;
            }
            if (!visible.contains(candidate.itemId())) {
                log.debug("[RAG] 丢弃不可见条目的召回块 itemId={}", candidate.itemId());
                continue;
            }
            // 同一篇文档的多个块命中时只留最相关的，避免 prompt 被单篇文档占满
            bestPerItem.merge(candidate.itemId(), candidate,
                    (a, b) -> a.score() >= b.score() ? a : b);
        }

        List<RetrievedChunk> result = new ArrayList<>(bestPerItem.values());
        result.sort((a, b) -> Double.compare(b.score(), a.score()));

        int topK = properties.getRetrieve().getTopK();
        return result.size() > topK ? result.subList(0, topK) : result;
    }

    /** 真正的向量查询。抽成 protected 便于测试替换。 */
    protected List<RetrievedChunk> vectorSearch(String question, int topK) {
        List<Document> documents = vectorStore.similaritySearch(
                SearchRequest.builder()
                        .query(question)
                        .topK(topK)
                        .similarityThreshold(0.0)
                        .build());

        List<RetrievedChunk> chunks = new ArrayList<>();
        for (Document document : documents) {
            Map<String, Object> metadata = document.getMetadata();
            Object itemId = metadata.get("itemId");
            if (itemId == null) {
                continue;
            }
            chunks.add(new RetrievedChunk(
                    ((Number) itemId).longValue(),
                    String.valueOf(metadata.getOrDefault("title", "")),
                    String.valueOf(metadata.getOrDefault("headingPath", "")),
                    document.getText(),
                    document.getScore() == null ? 0.0 : document.getScore()));
        }
        return chunks;
    }
}
```

```java
package com.njupt.kms.qa.config;

import com.njupt.kms.qa.retrieve.RetrievedChunk;

import java.util.List;

/** RAG 的提示词。单独成类便于单测与评审。 */
public final class QaPrompts {

    /** 单块注入 prompt 的最大字符数，防止个别超长块吃光上下文预算。 */
    static final int MAX_CHUNK_CHARS = 1200;

    private QaPrompts() {
    }

    /**
     * 系统提示。四条规则缺一不可，其中第 2 条是防幻觉的核心：
     * 不强制「答不上来就说没有」的话，模型会用通用知识编一个看起来合理的答案，
     * RAG 就退化成了普通聊天。
     */
    public static final String SYSTEM = """
            你是知识库问答助手。请严格依据用户消息中提供的资料回答问题。

            规则：
            1. 只使用资料中的信息，不要引入资料之外的任何知识
            2. 资料不足以回答时，明确回答「知识库中没有相关内容」，不要编造
            3. 回答中用 [1][2] 标注依据来自哪条资料
            4. 若多条资料互相矛盾，指出矛盾并分别说明

            回答使用简体中文，简洁准确，不要复述资料原文。
            """;

    public static String buildUserPrompt(String question, List<RetrievedChunk> chunks) {
        StringBuilder builder = new StringBuilder();

        if (chunks == null || chunks.isEmpty()) {
            builder.append("""
                    【资料】
                    没有检索到相关资料。

                    """);
        } else {
            builder.append("【资料】\n");
            for (int i = 0; i < chunks.size(); i++) {
                RetrievedChunk chunk = chunks.get(i);
                builder.append('[').append(i + 1).append("] 《")
                        .append(chunk.title()).append('》');
                if (chunk.headingPath() != null && !chunk.headingPath().isBlank()) {
                    builder.append(" / ").append(chunk.headingPath());
                }
                builder.append('\n').append(truncate(chunk.text())).append("\n\n");
            }
        }

        builder.append("【问题】\n").append(question);
        return builder.toString();
    }

    private static String truncate(String text) {
        if (text == null) {
            return "";
        }
        String stripped = text.strip();
        return stripped.length() <= MAX_CHUNK_CHARS
                ? stripped
                : stripped.substring(0, MAX_CHUNK_CHARS) + "……";
    }
}
```

```java
package com.njupt.kms.qa.service;

import com.fasterxml.jackson.databind.ObjectMapper;
import com.njupt.kms.qa.dto.QaMessage;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.data.redis.core.StringRedisTemplate;
import org.springframework.stereotype.Service;

import java.time.Duration;
import java.util.ArrayList;
import java.util.List;

/**
 * 问答会话历史，存 Redis。
 *
 * <p>沿用 TokenStore 的做法：只依赖模板，不引额外抽象。
 * 会话保留 7 天，与登录令牌一致。
 */
@Slf4j
@Service
@RequiredArgsConstructor
public class QaHistoryService {

    private static final String KEY_PREFIX = "kms:qa:chat:";
    private static final Duration TTL = Duration.ofDays(7);
    private static final int MAX_MESSAGES = 40;

    private final StringRedisTemplate redisTemplate;
    private final ObjectMapper objectMapper;

    public void append(String chatId, QaMessage message) {
        if (chatId == null || chatId.isBlank()) {
            return;
        }
        try {
            String key = KEY_PREFIX + chatId;
            redisTemplate.opsForList().rightPush(key, objectMapper.writeValueAsString(message));
            redisTemplate.opsForList().trim(key, -MAX_MESSAGES, -1);
            redisTemplate.expire(key, TTL);
        } catch (Exception e) {
            // 会话历史写失败不影响本次问答
            log.warn("[RAG] 会话历史写入失败 chatId={}", chatId, e);
        }
    }

    public List<QaMessage> history(String chatId) {
        if (chatId == null || chatId.isBlank()) {
            return List.of();
        }
        List<String> raw = redisTemplate.opsForList().range(KEY_PREFIX + chatId, 0, -1);
        if (raw == null) {
            return List.of();
        }
        List<QaMessage> messages = new ArrayList<>(raw.size());
        for (String json : raw) {
            try {
                messages.add(objectMapper.readValue(json, QaMessage.class));
            } catch (Exception e) {
                log.warn("[RAG] 会话消息反序列化失败，已跳过");
            }
        }
        return messages;
    }

    public void clear(String chatId) {
        if (chatId != null && !chatId.isBlank()) {
            redisTemplate.delete(KEY_PREFIX + chatId);
        }
    }
}
```

```java
package com.njupt.kms.qa.service;

import com.njupt.kms.qa.config.QaPrompts;
import com.njupt.kms.qa.dto.SourceRef;
import com.njupt.kms.qa.retrieve.RetrievalService;
import com.njupt.kms.qa.retrieve.RetrievedChunk;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.ai.chat.client.ChatClient;
import org.springframework.stereotype.Service;
import reactor.core.publisher.Flux;

import java.util.List;

@Slf4j
@Service
@RequiredArgsConstructor
public class QaService {

    private final RetrievalService retrievalService;
    private final QaHistoryService historyService;
    private final ChatClient qaChatClient;

    /**
     * 一次问答。返回引用来源与答案增量流。
     *
     * <p>刻意先做召回、再开始流式生成：调用方可以先把「引用来源」推给前端，
     * 用户立刻看到系统找到了什么，再等答案逐字出现。
     */
    public QaAnswer ask(String question, String chatId) {
        // 可见性由 RetrievalService 内部按 CurrentUser 判定，此处不重复传参
        List<RetrievedChunk> chunks = retrievalService.retrieve(question);
        List<SourceRef> sources = chunks.stream()
                .map(c -> new SourceRef(c.itemId(), c.title(), c.headingPath(), c.score()))
                .toList();

        historyService.append(chatId, com.njupt.kms.qa.dto.QaMessage.user(question));

        StringBuilder collected = new StringBuilder();
        Flux<String> stream = qaChatClient.prompt()
                .user(QaPrompts.buildUserPrompt(question, chunks))
                .stream()
                .content()
                .doOnNext(collected::append)
                .doOnComplete(() -> historyService.append(chatId,
                        com.njupt.kms.qa.dto.QaMessage.assistant(collected.toString(), sources)))
                .doOnError(e -> log.error("[RAG] 生成失败", e));

        return new QaAnswer(sources, stream);
    }

    /** 引用来源 + 答案流。 */
    public record QaAnswer(List<SourceRef> sources, Flux<String> stream) {
    }
}
```

```java
package com.njupt.kms.qa.controller;

import com.njupt.kms.common.BusinessException;
import com.njupt.kms.common.Result;
import com.njupt.kms.qa.dto.QaMessage;
import com.njupt.kms.qa.dto.QaStatusVO;
import com.njupt.kms.qa.index.IndexStatus;
import com.njupt.kms.qa.index.IndexingService;
import com.njupt.kms.qa.service.QaHistoryService;
import com.njupt.kms.qa.service.QaService;
import com.njupt.kms.security.CurrentUser;
import jakarta.validation.constraints.NotBlank;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.http.MediaType;
import org.springframework.http.codec.ServerSentEvent;
import org.springframework.validation.annotation.Validated;
import org.springframework.web.bind.annotation.DeleteMapping;
import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.PathVariable;
import org.springframework.web.bind.annotation.PostMapping;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RequestParam;
import org.springframework.web.bind.annotation.RestController;
import reactor.core.publisher.Flux;

import java.util.List;
import java.util.Map;

@Slf4j
@Validated
@RestController
@RequestMapping("/api/qa")
@RequiredArgsConstructor
public class QaController {

    private final QaService qaService;
    private final QaHistoryService historyService;
    private final IndexingService indexingService;

    /**
     * 流式问答。公开接口——未登录也能提问，但只能基于已发布内容。
     *
     * <p>事件顺序：sources → delta × N → done。出错时发 error 后结束，
     * 不抛异常（SSE 已开始响应，抛异常只会让前端拿到半截连接）。
     */
    @GetMapping(value = "/ask", produces = MediaType.TEXT_EVENT_STREAM_VALUE)
    public Flux<ServerSentEvent<Object>> ask(
            @RequestParam("question") @NotBlank String question,
            @RequestParam(value = "chatId", required = false) String chatId) {

        String conversationId = (chatId == null || chatId.isBlank())
                ? java.util.UUID.randomUUID().toString().replace("-", "")
                : chatId;

        try {
            // 可见性判定发生在 RetrievalService 内部（按 CurrentUser），此处无需处理
            QaService.QaAnswer answer = qaService.ask(question, conversationId);

            Flux<ServerSentEvent<Object>> sources = Flux.just(
                    ServerSentEvent.builder().event("sources").data(answer.sources()).build());

            Flux<ServerSentEvent<Object>> deltas = answer.stream()
                    .map(token -> ServerSentEvent.builder().event("delta").data(token).build());

            Flux<ServerSentEvent<Object>> done = Flux.just(
                    ServerSentEvent.builder().event("done")
                            .data(Map.of("chatId", conversationId)).build());

            return Flux.concat(sources, deltas, done)
                    .onErrorResume(e -> {
                        log.error("[RAG] 流式问答失败", e);
                        String message = e instanceof BusinessException ? e.getMessage() : "生成失败，请稍后重试";
                        return Flux.just(ServerSentEvent.builder().event("error")
                                .data(Map.of("message", message)).build());
                    });

        } catch (BusinessException e) {
            // 召回阶段就失败（未启用、问题为空）：直接以 error 事件结束
            return Flux.just(ServerSentEvent.builder().event("error")
                    .data(Map.of("message", e.getMessage())).build());
        }
    }

    @GetMapping("/history/{chatId}")
    public Result<List<QaMessage>> history(@PathVariable String chatId) {
        return Result.ok(historyService.history(chatId));
    }

    @DeleteMapping("/history/{chatId}")
    public Result<Void> clearHistory(@PathVariable String chatId) {
        historyService.clear(chatId);
        return Result.ok();
    }

    @GetMapping("/status")
    public Result<QaStatusVO> status() {
        IndexStatus status = indexingService.status();
        return Result.ok(new QaStatusVO(status.enabled(), status.indexedItems(),
                status.indexedChunks(), status.lastRebuildAt()));
    }

    /** 全量重建索引。管理员操作，耗时较长（并发下 500 块约 25 秒）。 */
    @PostMapping("/reindex")
    public Result<QaStatusVO> reindex() {
        CurrentUser.getRequired();
        IndexStatus status = indexingService.rebuildAll();
        return Result.ok(new QaStatusVO(status.enabled(), status.indexedItems(),
                status.indexedChunks(), status.lastRebuildAt()));
    }
}
```

## 已知限制（记入报告第七部分）

1. **单块向量化延迟约 350ms 且端点不支持批量**，全量重建依赖并发（8 路下 500 块约 25 秒），不是秒级。
2. **索引与状态变更之间存在窗口期**，本计划用「召回后按真实可见性二次过滤」兜底，但索引本身仍是最终一致的。
3. **不做 rerank**：召回只靠向量相似度，没有引入精排模型。若时间允许可作为后续项。
4. **不索引附件**：`attachment.parsed_text` 已是现成的切块输入源，但 v0.1.0 只索引条目正文，附件索引留作后续。
